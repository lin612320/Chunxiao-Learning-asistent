## 安装与使用

1. 双击 `春晓_0.6.1_x64-setup.exe` 安装（覆盖安装请**先关闭正在运行的春晓**）。
2. **本版重点用法**：做题/看板书时**截图（Win+Shift+S）→ 切到春晓或悬浮球 → `Ctrl+V`**，
   图片会挂在输入区；打字提问（也可以只发图），点「发送」。
3. 若提示"当前模型看不了图片"：到「数据设置 → 图片识别」单独指定一个能看图的模型
   （qwen-vl / gpt-4o / glm-4v 等），或在同一页把「图片提问方式」改成「先转成文字」。
   该页会**如实显示"现在会怎么走"**，不必猜。
4. **悬浮球**：面板顶部的「课程」下拉决定"材料检索查哪门课 / 问答归到哪门课"；
   默认「不限定课程」，**不会**自动套用你上次用的课程（要切换请显式选）。
5. 悬浮球面板下方就是把内容发给春晓的地方（选中文字会自动填进去）；「材料」按钮在本机材料里找关联内容。

## 诚实边界（产品口径，对外文案请保持一致）

> 自 **0.6.0** 起，下列口径在**主界面用大白话表述**，精确措辞收在页面内的可折叠「说明」区
> （`src/components/TechNote.tsx`）。折叠≠删除：展开即可逐字查证，冒烟脚本会**先展开折叠区再逐字校验**。

- **BYOK**：不内置共享 API Key；未配 Key 时进入演示模式并明确告知"这不是 AI 的回答"。
- **图片的三种命运都要说清**：① 交给能看图的模型（最准）；② 由视觉模型**转成文字**，转写文字标「模型转写，非原文」；
  ③ 两者都没有 → **明确报错**，绝不说"我看过了"。图片本身会随消息存在本机，不随请求外传别处。
- **AI 生成的内容一律"待核对"且不自动保存**：先验知识、笔记、题库出题、从对话提炼的知识，都是"生成 → 预览 → 确认才保存"。
- **掌握度是统计量**：每条并列显示支撑的作答次数；作答少于 3 次只显示灰态「样本不足」。
  **这里只做统计加权与提示词调整，不是强化学习 —— 模型权重不会因此改变。**
- **检索是关键词召回**，不是语义检索；界面会如实显示这次用了哪些词。
- **批注位置对不上时会明说**；**笔记的"当天问答记录"按消息落库时间归档**（技术债 T23）。
- **PDF 通过浏览器打印**；**番茄钟只计时与记录，不改动任何模型**。
- **形象为原创**：吉祥物「晨光云朵」全部由自绘几何图形构成，不含任何第三方美术素材。
- **面向课后理解与复习，不面向考试场景**；数据全部保存在本机（`%APPDATA%\com.chunxiao.study\chunxiao.db`），不做云同步、不上传材料。
