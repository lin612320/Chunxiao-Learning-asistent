# 春晓学习助手 · 交付包说明

**版本**：0.9.1（主程序 / 桌面壳）　**悬浮球**：1.0.9（**本版未重打**，源码未改动）　**构建日期**：2026-09-27　**适用平台**：Windows x64

> ⚠ **本版是「相关材料」版**：侧栏新增**「相关材料」**，**点材料就能用系统默认程序打开原文件**
> （PDF 就用你的 PDF 阅读器打开），并支持「在文件夹中显示」/「补存原文件」/ 删除。
> 主题、外观、笔记编辑器**与 0.9.0 完全相同**。
> 从 0.9.0 或更早覆盖安装都行；**装之前请先关闭正在运行的春晓与春晓助手**。
> 要回退：`春晓_0.9.0_x64-setup.exe`（有笔记编辑器、没有「相关材料」）。

## 本版改了什么（R13）

### 1. 侧栏「相关材料」：点材料直接打开原文件

**先说一个前提 —— 这件事在本版之前是做不到的**：

材料的正文一直是按**字节**导入的（选文件时浏览器只给得出文件内容、**给不出文件路径**），
所以库里存的 `file_path` **一直是空的**，而"用系统程序打开"必须要有一个真实路径。
两边合起来的结果是：**这个能力（`open_file`）从项目建立起就没有被用过一次**。

本版把这一环补上：

- **导入时在本机留一份副本**，并存下它的真实路径 —— 所以从本版起导入的材料，
  **点「打开」就能打开原文件**；而且以后你把原文件移走、改名甚至删掉，春晓这边照样能打开。
- **侧栏新增「相关材料」**（选中某门课时列该课的；「全部课程」时按课程分组列全部）：
  每一条都有 **打开** / **在文件夹中显示** / **删除**。
- 副本文件放在 `%APPDATA%\com.chunxiao.study\materials\`，名字形如
  `原名__内容指纹.ext`（指纹保证**同名不同内容不会互相覆盖**、**同内容不重复占两份**）。
  ⚠ 代价：材料会在本机**多占一份磁盘**（单文件上限 20 MB）。

### 2. ⚠ 你**现有的**材料需要先「补存原文件」

本版之前导入的材料**都没有副本**（`file_path` 是空的），所以它们**打不开**。
界面上**不摆一个点了没反应的「打开」按钮**，而是明说「**只导入过内容，没有原文件位置**」，
并给一个「**补存原文件**」—— 重新选一次那个文件，春晓会留一份副本并记下位置，之后就能打开了。

> 补存**只补位置**：正文、检索切块、以及「模型转写 · 非原文」这类来源标注**都不会被改动**。

### 3. 顺手修掉一处口径不自洽

打开文件的类型白名单里**缺 `pptx`** —— 而应用本来就能导入 pptx，结果是"导得进来、点开却说不支持"。已补上。

## 上一版改了什么（0.9.0 · R12）

### 1. 修掉「创建课程后，左上角课程选择不跟着更新」

- **现象**：在课程列表里新建一门课，跳进课程详情后，**侧栏的课程选择器里没有这门新课**，
  顶栏的「当前课程」胶囊也不出现 —— 只有按 F5 整页刷新才会出现。
- **根因**：负责课程列表的 `useCourses` 是个**普通 hook**，**10 个调用方各拿一份独立副本**，
  各自在挂载时拉一次数据；而侧栏选择器与顶栏胶囊是**常驻组件**（切页面不重新挂载），
  于是**只有"发起新建"的那一份**会刷新。新课对其它九份来说**到整页刷新前根本不存在**。
- **修法**：改成**全应用唯一的一份共享存储**（写入即广播给所有使用方），
  新建的课还会**立刻成为当前课程**（顶栏胶囊同步出现）。
  顺带把启动时的数据请求从 **10 次降到 1 次**。

### 2. 笔记：沉浸式多模态编辑器（新）

点笔记列表里的任意一条，进入**没有侧栏、没有顶栏**的文档视图：

| 能力 | 说明 |
| --- | --- |
| **文字** | Markdown 源码输入 + **右侧实时预览**；可选「编辑 / 分栏 / 预览」三档 |
| **图片** | **粘贴（Ctrl+V）/ 拖进来 / 选文件** 三条入口；自动压到 1600px 长边、单条上限 3 MB，**放不下的会逐条告知原因** |
| **公式** | 行内 `$E = mc^2$` 与独立居中的 `$$…$$`（内置 KaTeX 本机渲染，**不联网**） |
| **代码块** | 工具栏一键插入（也可直接写 ` ``` `） |
| **标题层级** | H1 / H2 / H3 / 正文 一键切换（字号层级与笔记阅读视图一致） |
| 其它 | 引用、有序/无序列表、链接、表格、分隔线；`Ctrl+S` 保存、`Ctrl+B` 加粗、`Ctrl+I` 斜体；回车自动续列表；**有未保存改动离开会拦一次** |

> 原来在笔记页右侧的**预览 / 批注 / 导出**一条路也保留了：条目上多了一个「阅读」按钮。

### 3. ⚠ 本版引入了一个第三方前端依赖

公式渲染用的是 **KaTeX**（`katex@0.16.11`）—— 这是本项目**历史上第一个第三方前端依赖**
（此前图标、Markdown 渲染器全是手写的）。代价已量化：安装包 **82.4 MB → 83.33 MB**，
release exe **5.23 MB → 6.13 MB**（含公式字体 60 个文件）。

### 4. 顺带补上的一个真缺口

写笔记时「贴了图片、预览里却什么都不显示」。查下来是**两层叠加**：
渲染器**从来没有图片规则**，而图片地址的协议白名单**刻意拒掉了 `data:`**（那是挡注入的安全设置）。
已补上图片规则 + **图片专用的更窄白名单**（只放行 png/jpeg/webp/gif，**刻意排除 svg**）。

## 怎么用（重点说一遍）

1. 双击 `春晓_0.9.1_x64-setup.exe` 安装（覆盖安装请**先关闭正在运行的春晓与春晓助手**）。
2. **打开就是课程列表** → 点一门课进入，或在**侧栏顶部选择器**里选一门；
   然后侧栏会出现这门课的：课程总览 / **笔记** / **相关材料** / **题库** / **与该课对话** / **学习画像**。
   > 0.9.0 起：**新建课程后侧栏选择器会立刻出现这门课**，并自动选中它。
3. **看材料（本版重点）**：侧栏 →「**相关材料**」→ 每条材料都有「**打开**」（用系统默认程序打开原文件，
   PDF 就用你的 PDF 阅读器）与「在文件夹中显示」。
   > ⚠ **本版之前导入的材料**要先点一次「**补存原文件**」：重新选一下那个文件，春晓会留一份副本并记下位置，
   > 之后就能打开了。**本版起新导入的材料会自动留副本，直接用「打开」即可。**
4. **写笔记**：笔记页 → 点任意一条笔记 → 进入**沉浸式编辑页**：
   - 左边写 Markdown、右边实时看效果（也可以用顶部「编辑 / 分栏 / 预览」切换）；
   - **贴图**：直接 `Ctrl+V`，或把图片拖进来，或点工具栏的图片按钮选文件；
   - **写公式**：行内用 `$…$`，独立一行用 `$$…$$`（例如 `$\int_0^1 x^2\,dx$`）；
   - `Ctrl+S` 保存；有改动没保存就点「返回」会问你一句。
5. **问春晓**：对话页底部输入框，**回车发送、Shift+回车换行**；回答是 Markdown 渲染的，
   下面会列出参考来源。
6. **悬浮球**：`Win+Shift+S` 截图 → `Ctrl+V` 粘进面板 → 写问题 → 回车。
   球面默认是一只**蓝鲸**；想换外观 / 主题，右键托盘或面板里打开「换肤」。
   面板顶部的「课程」下拉会**跟着主窗口当前课程走**，也可以在那里单独改。
7. **一键核对**：课程页「先验知识」右上角 → 「一键核对（N 条）」，把「待核对」一次标掉。
8. 「全部课程」态下可以看到跨课程的**全部笔记 / 全部材料 / 全部题库 / 学习画像**。

## 诚实边界（产品口径，对外文案请保持一致）

- **BYOK**：不内置共享 API Key；未配 Key 时进入演示模式并明确告知"这不是 AI 的回答"。
- **图片的三种命运都要说清**：交给能看图的模型 / 由视觉模型转成文字（标「模型转写，非原文」）/
  两者都没有就**明确报错**，绝不说"我看过了"。
  **笔记里的图片只存在你本机**（以 dataURL 内联在笔记正文里），不联网、不上传。
- **公式在本机渲染**（内置 KaTeX），**不联网**。
- **AI 生成的内容一律"待核对"且不自动保存**；手写的标「自己写的」。先验知识 `verified = 0`、来源可溯源。
- **不做屏幕抓取**：抓取电脑画面由你自己用系统截图工具完成再粘进来。
- **掌握度是统计量**：并列显示支撑的作答次数；少于 3 次只显示灰态「样本不足」。
  **不是强化学习 —— 模型权重不会因此改变。**
- **检索是关键词召回**，界面会如实显示这次用了哪些词；「关联知识点」分别标出三类命中，命中 0 条也说清是"没查到"。
- **批注位置对不上时会明说**；**笔记的"当天问答记录"按消息落库时间归档**（债 T23）。
- **面向课后理解与复习，不面向考试场景**；数据全部保存在本机（`%APPDATA%\com.chunxiao.study\chunxiao.db`），
  不做云同步、不上传材料。
