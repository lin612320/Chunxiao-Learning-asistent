## 安装与使用

1. 双击 `春晓_0.6.0_x64-setup.exe` 安装（覆盖安装请**先关闭正在运行的春晓**）。
2. 首次启动 → 「数据设置」填**自己的** API Key（不内置共享 Key）；未配置时进入演示模式，界面会明确说明"这不是 AI 的回答"。
3. 悬浮球随主程序一起工作；也可直接运行便携版。
4. **本版界面**：主界面只讲大白话；公式、检索机制、存储路径、备份内容等**技术细节收在页面内的可折叠「说明」区**，展开即可查证（诚实边界一条没删）。
5. **对话按课程展开**（0.4.0 起）：进课程详情页点「**与该课程对话**」，会话与材料检索都会限定在这门课；在该课程下聊过之后，回到课程页可用「**从本课对话提炼先验知识**」（生成 → 预览可勾选可编辑 → **确认才保存**）。

- **包内悬浮球是 1.0.3**（不是推断）：暂存资源目录 `target/release/win-unpacked-0.6.0/春晓助手.exe` 实测 `ProductVersion=1.0.3`、188,833,792 B、SHA256 `4E86073C23714FBDF3F17493684670DD8EA3C5EA038C126B4A9B4C3AA10E6A7B`
- **图标"真的写进去了"是抽出来看过的**：主程序 exe 与包内悬浮球 exe 的内嵌图标，用 `PrivateExtractIcons` 按尺寸抽出后 **`@256px` 与 `@32px` 两者 SHA256 逐位相同**（`C0C62817C9AC67A8…` / `9F3778F8FC671E1D…`），目视均为「晨光云朵」
  - ⚠ **方法学记录**：首次用 `System.Drawing.Icon.ExtractAssociatedIcon` 抽取时，**悬浮球 exe 抽出的是一块纯绿色圆角方块（没有吉祥物）**，Hash 与主程序不一致 —— 一度像是"包内图标不对"。改用 `PrivateExtractIcons`（按尺寸从图标资源组取）后两者逐位相同。**结论：对 Electron 打包的 exe，不要用 `ExtractAssociatedIcon` 做图标核验**（它会取到错误的图标项），否则会得到假警报。
- **一个真实差异（非缺陷）**：主程序图标 `@256px` 与 `@32px` 的哈希不同是**正常的** —— ICO 里各尺寸是独立位图；可比的是"同一尺寸在两个 exe 之间是否一致"。

## 诚实边界（产品口径，对外文案请保持一致）

> ⚠ 自 **0.6.0** 起，下列口径在**主界面用大白话表述**，**精确措辞收在页面内的可折叠「说明」区**
> （`src/components/TechNote.tsx`）。折叠≠删除：展开即可逐字查证，冒烟脚本也会**先展开折叠区再逐字校验**。

- **BYOK**：不内置共享 API Key；未配 Key 时进入演示模式并明确告知"这不是 AI 的回答"。
- **AI 生成的内容一律"待核对"且不自动保存**：先验知识、笔记、**题库出题**、**从对话提炼的先验知识**，都是"生成 → 预览（可勾选可编辑）→ 确认才保存"。
- **从对话提炼的知识素材里含 AI 自己的回答**，提示词已逐字声明"那也是 AI 生成的、未经核实，不得当作事实依据"，保存时一律低置信（`confidence=0.4`）并标「从对话提炼 · 待核对」。
- **对话的课程归属由用户显式选择**：界面始终显示当前课程与检索范围；不点「切过去」就不会自动套用"最近使用的课程"。
- **掌握度是统计量**：每条并列显示支撑的作答次数；作答少于 3 次只显示灰态「样本不足」，不给数字、不进弱项榜。**这里只做统计加权与提示词调整，不是强化学习 —— 模型权重不会因此改变。**
- **检索是关键词召回**，不是语义检索；界面会如实显示这次用了哪些词（0.5.0 及以前写作"本轮检索词"）。
- **PDF / 图片**经模型转写的正文标注**「这是模型转写的，不是原文」**（0.5.0 及以前写作「模型解析，非原文」）；不做本地 OCR。
- **批注位置对不上时会明说**：标注「位置已自动修正」；全文找不到的批注进「已失效的批注」列表，不假装还在原位。
- **笔记的「当天问答记录」按消息落库时间归档**：当前实现里每次保存会话会把该会话消息的时间戳整体刷新，因此跨天续聊的内容可能被算到"最后一次保存的那天"（已登记为技术债 T23，见 `docs/12` §四）。
- **PDF 通过浏览器打印**（非服务端排版）；**番茄钟只计时与记录，不改动任何模型**。
- **形象为原创**：吉祥物「晨光云朵」全部由自绘几何图形构成，不含任何第三方美术素材（`docs/00` §4.3 的许可结论）。
- **面向课后理解与复习，不面向考试场景**；数据全部保存在本机（`%APPDATA%\com.chunxiao.study\chunxiao.db`），不做云同步、不上传材料。
