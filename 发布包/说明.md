# 春晓学习助手 · 交付包说明

**版本**：0.8.1（主程序 / 桌面壳）　**悬浮球**：1.0.9（本版**已重打**）　**构建日期**：2026-09-24　**适用平台**：Windows x64

> ⚠ **本版是「云鲸纸面」主题版**：整个界面（含**背景图**）换成你 DSH 里那套皮肤
> **「DeepSeek 云鲸纸面」**（作者 yunxi）—— 云鲸女仆插画背景 + 侧栏海浪 + 页边女仆 + 暮蓝纸面色板；
> **悬浮球（球面 / 面板 / 换肤窗）同步**；并**修掉悬浮球「点开设置后文字重叠」**。
> 从 0.7.x 或更早覆盖安装都行；**装之前请先关闭正在运行的春晓与春晓助手**。
> 要回退：`春晓_0.8.0_x64-setup.exe`（上一版主题）/ `春晓_0.7.2_x64-setup.exe`（R6 结构版）。

## 本版改了什么（R11 主题 + R11 修复 + R7~R10 的累积）

### 1. 主题换成「DeepSeek 云鲸纸面」（R11）

- **背景图**：主窗口铺**云鲸女仆插画**（+ 一层雾色保证可读），**侧栏**铺海浪图，左下角是**页边女仆**；
  圆角全部是**四角不等**的"手绘感"圆角。
- **悬浮球**：球面云鲸蓝 + 球上是**云鲸女仆**；面板铺同一张背景图与皮肤两套令牌；换肤窗也换了皮。
- ⚠ **修了一个真缺陷**：悬浮球「点开设置后文字重叠」——设置抽屉改成**覆盖层且不透明**；
  并给面板版面守门**补上抽屉那一层**（42 → **50** 条，负例 PASS 47 / FAIL 3 **能红**）。

### 2. 上一版（0.8.0）：主题换成 DSH 基座令牌

- **配色**：底色 浅 `#f9fafb` / 深 `#151517`，卡片 浅 `#fff` / 深 `#232324`，
  主操作 浅近黑 `#0f1115` / 深白 `#f9fafb`，品牌蓝 `#4176e6` / `#5686fe`。
  这批值**不是手调的**，是逐值照抄 DSH 主题包的令牌（`--dsw-static-*` / `--dsw-alias-*`）。
- **背景**：换成 DSH 的应用底色（原来那层"春绿晨光"渐变退役）。
- **形象**：换成 **DSH 的鲸鱼**，且 **App 图标 / 任务栏 / 悬浮球 / favicon 全部同一只蓝鲸**（近黑底盘）。
- **字体**：DSH 的字体栈。
- **悬浮球**：新增「**鲸鱼娘**」皮肤并设为默认（蓝色球面 + 白鲸）；
  面板与换肤窗的配色一并换成 DSH 的深浅两套。

### 2. 会前几轮一起带上的（R7~R9）

- **悬浮球的检索范围跟着主窗口当前课程走**（原来默认"全部课程"，与按钮上写的"这门课"不符）。
- **模型知道自己在哪门课里**：修掉"在《计算机系统基础》里问 IR，却得到各领域通用含义"那个缺陷。
- **对话页**：输入框与消息区**同宽**；AI 回复走 **Markdown 渲染**（不再显示一堆 `#`）。
- **笔记按天分组**：自己写的与 AI 从对话整理的**同列在一起**，点开即在软件内预览。
- **一键核对**：先验知识区一键把「待核对」全部标为已核对（只改标记，不改内容）。
- **回车发送、Shift+回车换行**（原来是 Ctrl+回车）。
- **顶部切换课程后，题库页与画像页的课程也跟着切**（原来这两页恒为第一门课）。
- **提示文案大量删减**：空状态只留「暂无记录。」这类状态词（**诚实边界一句没删**）。

## 怎么用（重点说一遍）

1. 双击 `春晓_0.8.0_x64-setup.exe` 安装（覆盖安装请**先关闭正在运行的春晓与春晓助手**）。
2. **打开就是课程列表** → 点一门课进入，或在**侧栏顶部选择器**里选一门；
   然后侧栏会出现这门课的：课程总览 / **笔记** / **题库** / **与该课对话** / **学习画像**。
3. **写笔记**：笔记页 → 「＋ 新建笔记」→ 写标题与正文 → 保存（来源标「自己写的」）；
   右侧列表按**天**分组，自己写的与 AI 整理的都在同一份里，点开就能读。
4. **问春晓**：对话页底部输入框，**回车发送、Shift+回车换行**；回答是 Markdown 渲染的，
   下面会列出参考来源。
5. **悬浮球**：`Win+Shift+S` 截图 → `Ctrl+V` 粘进面板 → 写问题 → 回车。
   球面默认是一只**蓝鲸**；想换外观 / 主题，右键托盘或面板里打开「换肤」。
   面板顶部的「课程」下拉会**跟着主窗口当前课程走**，也可以在那里单独改。
6. **一键核对**：课程页「先验知识」右上角 → 「一键核对（N 条）」，把「待核对」一次标掉。
7. 「全部课程」态下可以看到跨课程的**全部笔记 / 全部题库 / 学习画像**。

## 诚实边界（产品口径，对外文案请保持一致）

- **BYOK**：不内置共享 API Key；未配 Key 时进入演示模式并明确告知"这不是 AI 的回答"。
- **图片的三种命运都要说清**：交给能看图的模型 / 由视觉模型转成文字（标「模型转写，非原文」）/
  两者都没有就**明确报错**，绝不说"我看过了"。
- **AI 生成的内容一律"待核对"且不自动保存**；手写的标「自己写的」。先验知识 `verified = 0`、来源可溯源。
- **不做屏幕抓取**：抓取电脑画面由你自己用系统截图工具完成再粘进来。
- **掌握度是统计量**：并列显示支撑的作答次数；少于 3 次只显示灰态「样本不足」。
  **不是强化学习 —— 模型权重不会因此改变。**
- **检索是关键词召回**，界面会如实显示这次用了哪些词；「关联知识点」分别标出三类命中，命中 0 条也说清是"没查到"。
- **批注位置对不上时会明说**；**笔记的"当天问答记录"按消息落库时间归档**（债 T23）。
- **面向课后理解与复习，不面向考试场景**；数据全部保存在本机（`%APPDATA%\com.chunxiao.study\chunxiao.db`），
  不做云同步、不上传材料。
