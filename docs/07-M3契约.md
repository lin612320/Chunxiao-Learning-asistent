## 一、T2：最小 Markdown 渲染器（前端，**零依赖**）

新增 `src/lib/markdown.tsx`，导出：

```ts
export interface MdProps { text: string; className?: string; onSelectBlock?: (blockIndex: number) => void }
export default function Markdown({ text, className }: MdProps): ReactElement
export function splitBlocks(md: string): string[]   // 供批注锚点与 Rust 侧块序保持一致
```

**必须支持**：ATX 标题（`#`~`######`）、无序/有序列表（含嵌套一层）、代码块（``` 围栏，可带语言标注但不高亮）、行内代码、**粗体/斜体**、引用（`>`）、水平线（`---`）、**表格**（`| a | b |` + 分隔行）、链接（渲染为可点击 `<a>`，`target="_blank" rel="noreferrer"`）、段落与空行。

**安全红线（与 `highlight.tsx` 同源）**：
- **禁止** `dangerouslySetInnerHTML`、**禁止**拼接 HTML 字符串；一切用 React 元素渲染。
- 链接只允许 `http:` / `https:` / `mailto:`，其余（含 `javascript:`）**降级为纯文本**。
- 代码块内容原样作为文本节点渲染（React 自动转义）。

**块划分（`splitBlocks`）是批注锚点的地基**：把 Markdown 按**空行与块级边界**切成块数组，索引从 0 开始；**渲染顺序必须与 `splitBlocks` 的索引一一对应**（每个块渲染时带上 `data-block` 属性，便于验证与定位）。规则写清楚：表格整体算一块、代码块整体算一块、连续列表项算一块、单个标题/段落各算一块。

### 2.3 `.docx` 导出：**移植母本的 `docx.rs`**

母本 `src-tauri/src/docx.rs`（约 17 KB）是**自包含**的：自带 `zip_store`（STORE 方式，不需要 flate2）、`crc32`、`dos_datetime`、`xml_escape`，并把 Markdown 转成 OOXML（支持标题/段落/列表/引用/代码块/**原生表格**）。
公开入口：`pub fn export_docx(dir: &Path, title: &str, markdown: &str) -> Result<PathBuf, String>`。

**做法**：整份复制并只改文件头注释口径（含"法元/律政"字样 → 春晓）；`note_export_docx` 直接调它。**不新增任何 crate 依赖。**

## 三、批注锚点（本轮最容易做错的地方）

**问题**：`annotations` 原本只有字符偏移。笔记正文是 Markdown，渲染后块会重排；若笔记被重新生成/编辑，纯字符偏移会**静默指向错位置**（用户看到的批注跑到了别的句子上）。

**锚点定义（三个字段合起来才算一个锚）**：
1. `block_index`：块序号（与 `splitBlocks` / 渲染时的 `data-block` 一一对应）；
2. `start_off` / `end_off`：**在该块纯文本内**的字符偏移（不是全文字符偏移）；
3. `quote`：被标注的原文片段（**用于校验与自愈**）。

**自愈策略（必须实现，且要说人话）**：
- 渲染时先按 `block_index` + 偏移取文本，与 `quote` 比对；
- 不一致 → 在当前块（再退化为全文）里**搜索 `quote`**，找到就用新位置渲染，并**在界面上标注"位置已自动修正"**；
- 全文都找不到 → **不假装还在**，把该批注归入"**已失效的批注**"列表并显示其原文与批注内容，允许用户删除。

**关键词高亮**是另一回事：它不需要持久化（不写库），属于阅读辅助，可以直接复用 M2 的 `src/lib/highlight.tsx`（`<Highlight text terms />`）。

## 四、前端 UI

### 4.1 笔记页（`src/views/Notes.tsx` + 自带 `Notes.css`）

- **列表**：按课程筛选，显示标题 / 日期 / 来源徽标（`ai_session` → **「AI 整理 · 待核对」**；`user` → 「自己写的」）/ 已导出标记。
- **生成**：选课程 + 日期 → 收集**该课程当天会话的消息**（无当天消息时提示"今天还没有问答记录"，**不要**凭空生成）→ 调模型（提示词要求输出 Markdown 笔记：标题、要点分条、**术语与公式**、**存疑处显式标注**）→ **可编辑预览**（textarea）→ 点保存才入库（`source: "ai_session"`）。
  ⚠ 与"AI 生成先验知识"同一条红线：**不自动入库、不假装有 AI**（未配 Key 时按钮禁用并引导去数据设置）。
- **详情**：Markdown 渲染（`lib/markdown.tsx`）+ 批注层 + 导出按钮（md / docx / pdf）。
- **批注交互**：选中正文文字 → 弹出"高亮/批注"小面板（颜色 + 备注）→ 保存为批注；点击已有高亮可编辑/删除；失效批注单独成列。

### 4.2 番茄钟页（`src/views/Focus.tsx` + 自带 `Focus.css`）

- 专注时长（1–120 分钟）与休息时长（1–60 分钟）各用 `−` / `+` 调节，**偏好持久化到 localStorage**（键 `chunxiao:focus`）。
- 开始 / 暂停（继续）/ 重置；大号倒计时 `MM:SS` + 进度环或进度条；阶段结束**自动切到下一阶段**并继续。
- 阶段开始时调 `focus_start`，结束时调 `focus_finish` 并调 **`focus_notify`** 发系统通知（标题/正文写明"专注结束，休息一下"或"休息结束，继续加油"）。
- 展示**今日专注分钟数**与**近 7 天柱状图**（数据来自 `focus_stats`；无数据时如实显示"暂无记录"，不要造数据）。
- 页面需注明：**本页只是计时与记录，不改动任何模型**（诚实边界）。

### 4.3 路由与导航

`/notes` 与 `/focus` 从 `Placeholder` **替换为真实页面**，侧栏去掉"（M1/M2 实现）"之类的占位角标。
⚠ **`src/nav.ts` 与 `src/App.tsx` 由主代理统一改**，两个前端代理**不要动这两个文件**（避免并发冲突）。
⚠ `src/styles.css`（全局设计令牌）**不要动**；每个新页面自带独立 CSS 文件（沿用母本 `Evolution.css` / `KnowledgeGraph.css` 的做法）。
⚠ `src/data/sample.ts` **只由笔记代理改**（番茄钟不需要预览数据）；`src/lib/highlight.tsx` 只读复用，不改。

## 六、约束

1. **不改已冻结项**：命令名、既有返回字段名与类型、`enc.` 前缀、桥接文件名与载荷、路由结构、`styles.css` 设计令牌、`highlight.tsx` 的对外接口。
2. **不新增任何 npm / crate 依赖**（Markdown 渲染自己写；.docx 用母本自包含实现）。
3. **M0–M2 功能不得退化**：课程/先验知识/材料导入/检索与引用来源/悬浮球/BYOK/演示模式/`?float=1` 紧凑模式。
4. **诚实边界（必须落到界面文案与数据里）**：AI 整理的笔记标 `source='ai_session'` + 「待核对」徽标且**不自动入库**；PDF 导出用浏览器打印并如实说明；番茄钟页写明"只计时与记录，不改动模型"；无数据时显示"暂无记录"而不造数据。
5. Windows：`cargo` 写 stderr 会被 PowerShell 记成 NativeCommandError，**判成功看 `$LASTEXITCODE`**；含中文的 `.ps1` 必须带 UTF-8 BOM（质量闸门第 6 步已自动拦截）。
