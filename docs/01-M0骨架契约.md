## 四、数据表（M0 一次建齐，避免后续迁移）

按 `00-可行性评估.md` §6.3 的 17 张表全量建立：
`courses` / `course_prior` / `materials` / `material_chunks` / `chunks_fts`(FTS5) /
`chat_sessions` / `chat_messages` / `notes` / `annotations` / `knowledge_points` /
`questions` / `attempts` / `profile_traits` / `pet_state` / `focus_sessions` /
`todos` / `settings` / `mem_vectors`

- 迁移模式照抄母本 `db.rs`：`CREATE TABLE IF NOT EXISTS` + `ensure_column` 幂等补列。
- `settings` 的 `ai.api_key` 以 `enc.` 前缀混淆落盘（母本 `keycrypt.rs` 对称实现）。
- 播种：空库时写入一门示例课程（**明确标注为示例**），保证首启不是空白页。

### 四.1 前后端互操作口径（实现完成后冻结，联调以此为准）

| 项 | 冻结口径 | 理由 |
| --- | --- | --- |
| **命令参数** | JS 侧传 **camelCase**（`courseId` / `sessionId` / `file` / `dir`）→ Rust 侧形参 `snake_case` | Tauri v2 的自动映射；写错名字不会报"未知字段"，`Option` 会**静默变 None**（母本踩过） |
| **DB 行返回字段** | **snake_case，与 SQL 列名逐字一致**（`created_at` / `file_name` / `course_id` / `source_ref` / `extracted_by` / `size_bytes`） | 返回 `Value` 时不加 serde 重命名，前端按列名取值。**不要**给行结构体加 `rename_all = "camelCase"` |
| **空结果** | 一律返回**空数组 `[]`**，不返回 `null` | 前端按数组处理，`null` 会炸 |
| **api_key 加密职责** | **桌面**：前端只传**明文**，Rust 侧 `keycrypt.rs` 加密落盘、`settings_get` 返回**解密后的明文**。**浏览器预览**：由前端 `secret.ts` 负责加解密（localStorage） | 职责单一，避免双重加密。前端读取时对两种前缀都兼容，属防御性冗余 |
| **混淆前缀** | 统一 `enc.`（点号；母本为 `enc:` 冒号） | 与契约一致；Rust / 前端两侧都已对齐 |
| **`ball_start_cmd`** | **无参** | 启动后一切指令经控制文件 `to-ball.json` 下发，不走进程参数（母本踩过坑，见母本架构文档 §6.7） |
| **`extract_material` 的 pdf / 图片** | 明确表示"暂不支持"，**不假装支持**；具体形状（`Err` 还是带 `note` 的 `Ok`）以 Rust 实现为准并在实现记录中登记 | 诚实边界口径 |

## 六、双环境降级（照抄母本）

`src/lib/tauri.ts` 的 `isTauri()` 判断 `window.__TAURI_INTERNALS__`：
- 桌面版：`callRust()` 走 `invoke`，数据入 SQLite。
- 浏览器预览：`callRust()` 返回 `null`，各 hook 降级到 `src/data/` 示例数据 —— 前端可脱离 Rust 调 UI。
