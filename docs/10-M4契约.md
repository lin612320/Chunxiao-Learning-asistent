## 一、口径红线（**比功能更重要，必须逐条落实**）

1. **掌握度是统计量，不是"模型学会了"**：只允许由作答记录算出的加权准确率，**必须同时显示支撑样本数**（`evidence`）。
2. **样本不足不展示结论**：`attempts < 3` 的知识点显示「样本不足」灰态，**不给掌握度数字、不进弱项榜**。
3. **画像页必须有一块显式声明**（原文照用，不要改写）：
   > **这里只做统计加权与提示词调整，不是强化学习 —— 模型权重不会因此改变。**
   > 作答正确率与偏好只影响本机的选题顺序与解释粒度；上传与训练都不发生。
4. **禁止**出现"智能体自我进化 / 越用越聪明 / 模型在学习"这类表述。UI 文案一律用「**本机统计**」。
5. **AI 生成的题目不自动入库**：必须**预览 → 可编辑 → 确认才保存**，且 `source='ai'`；题目与答案**必须可人工校正**（`flawed` 标记）。
6. **无数据时如实显示"暂无记录 / 样本不足"**，不造数据、不画假的曲线。

## 二、后端新增命令（Rust）

参数 **camelCase**、行字段 **snake_case**、空列表 `[]`、写入失败给可读中文错误（与既有口径一致）。

### 2.1 知识点

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `knowledge_points_list` | `courseId` | `Vec<Value>`：`id / course_id / prior_id / name / parent_id / question_count / attempts / correct` |
| `knowledge_point_save` | `courseId, name, priorId?, parentId?` | `i64`（同名同课程已存在则返回既有 id，不重复插） |
| `knowledge_points_sync_from_prior` | `courseId` | `Value`：`{ created, total }` —— 从该课程的**先验知识树**派生出知识点（用 `prior_id` 关联；`topic` 作为 `name`，`parent_id` 按先验的父子关系映射）。**幂等**：已存在的（同 `course_id` + `prior_id`）不重复建 |

### 2.2 题库

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `questions_list` | `courseId?, kpId?, limit?` | `Vec<Value>`（列表**不返回 options 全文以外的重型字段**，够用即可；含 `attempts`、`last_correct`） |
| `question_get` | `id` | `Value`（全字段） |
| `question_save` | `courseId, kpId?, qtype, stem, options?, answer, explain?, difficulty?, source, sourceRef?` | `i64` |
| `questions_save_batch` | `courseId, items`（数组） | `Vec<i64>` —— **批量入库**，避免前端 N 次 IPC（M3 已因此留下 T20 的教训） |
| `question_update` | `id, stem?, options?, answer?, explain?, difficulty?, flawed?` | `()`（**人工校正**入口） |
| `question_delete` | `id` | `()`（级联删除其 `attempts`） |

- `qtype` 取值：`choice` / `blank` / `short` / `essay`，**校验非法值**。
- `options` 以 **JSON 字符串**存（选择题：`["A项","B项",...]`），Rust 侧校验**能被解析为 JSON 数组**，否则报可读错误。
- `flawed` 为 `bool`（前端传 `true/false`，落库为 `0/1`，与既有 `flag()` 口径一致）。

### 2.3 练习与作答

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `practice_pick` | `courseId, kpId?, count?`（默认 5，上限 50） | `Vec<Value>`：**按"弱项优先"排序**的题目（排序规则见下） |
| `attempt_record` | `questionId, userAnswer?, correct?, selfEval?, durationMs?, confidence?` | `i64` |
| `attempts_list` | `courseId?, kpId?, onlyWrong?, limit?` | `Vec<Value>`（**错题本数据源**；含题目 `stem` / `qtype` / `answer` / `explain`、作答与时间） |

- **`practice_pick` 的排序规则（必须是可解释的统计加权，不许叫"智能"）**：
  1. 从未作答的题目优先；
  2. 其次按所属知识点的**掌握度升序**（越弱越先）；
  3. 同分按 `id` 稳定排序。
- `correct` 允许 `None`（主观题待自评）；`selfEval` 取值 `0/1`；`durationMs`、`confidence`（1–5）可空。**校验**：`confidence` 超出 1–5、`durationMs` 为负 → 报可读错误。

### 2.4 统计与画像

| 命令 | 参数 | 返回 |
| --- | --- | --- |
| `question_stats` | `courseId` | `Value`：**按知识点聚合**的数组，每项 `{ kp_id, kp_name, questions, attempts, correct, accuracy, mastery, evidence, last_at }` |
| `profile_traits_list` | `courseId?` | `Vec<Value>` |
| `profile_trait_set` | `kpId?, trait, value?, evidence?` | `i64` |
| `profile_overview` | `courseId` | `Value`：`{ mastery: [...], weak_points: [...], not_enough: [...], declared_gaps: [...], preferences: [...], min_evidence }` |

**掌握度公式（必须写进代码注释与界面 tooltip）**：

```
mastery = (correct + 1) / (attempts + 2)      // 拉普拉斯平滑，避免 0/0 与 1/1 的极端
evidence = attempts
```

- `min_evidence = 3`：`attempts < 3` 的条目**只进 `not_enough`**，不进 `mastery` 的有效结论、不进 `weak_points`。
- `accuracy` 为原始 `correct / attempts`（`attempts = 0` 时为 `null`），与 `mastery` **并存展示**，避免读者误以为平滑值是原始正确率。
- `trait` 取值：`mastery`（系统算，只读）/ `weakness_self`（**用户自述缺漏**）/ `preference` / `style`，**校验非法值**。
- `weak_points` 排序：`mastery` 升序，取前 10；**每项必须带 `evidence`**。
- 全部为**本机查询**，无网络、无上传。

## 三、前端 UI

### 3.1 题库页（`src/views/Questions.tsx` + 自带 `Questions.css`）

- **知识点同步**：顶部按钮「从先验知识同步知识点」→ `knowledge_points_sync_from_prior`，返回 `{created,total}` 并**如实提示**（"新建 5 个，共 12 个"）。
- **生成题目**：选课程 + 知识点（可多选）+ 数量 → 收集该知识点的**先验知识摘要与材料片段**（`material_search` 可复用）→ 调模型，提示词要求**严格 JSON 数组**：
  `[{"qtype":"choice|blank|short|essay","stem":..., "options":[...]?, "answer":..., "explain":..., "difficulty":1-5, "kp_name":...}]`
  → **解析容错**（容忍 ```json 围栏）→ **可勾选可编辑预览** → 点「确认入库」才调 `questions_save_batch`（`source:"ai"`）。
  ⚠ 未配 Key 时按钮禁用并引导去数据设置；**不用模板假造题目冒充 AI 生成**。
- **列表与筛选**：按知识点 / 题型 / 是否标记有问题筛选；每题可**编辑题干/答案/解析**（`question_update`）、**标记"题目有问题"**（`flawed`）、删除。
- **练习模式**：`practice_pick` 取题 → 逐题作答 → 客观题**本地判分**（选择/填空）→ `attempt_record`；主观题展示参考答案后由用户**自评**（`selfEval`）→ `attempt_record`；过程中可记录 `durationMs` 与 `confidence`。
- **错题本**：`attempts_list(onlyWrong: true)`；可「重练错题」（把这些题喂给练习模式）。

### 3.2 画像页（`src/views/Profile.tsx` + 自带 `Profile.css`）

- **掌握度视图**：`profile_overview` → 按知识点的**热力图或条状图**；每条显示 `mastery`（百分比）与 **`evidence`（样本数）**。
  - `not_enough` 的条目以**灰态**显示「样本不足（n 次）」——**不给数字**。
  - tooltip 写明公式与平滑说明（§2.4）。
- **弱项**：`weak_points` 列表，**每条必须显示样本数**；点击可跳到该知识点的题目。
- **自述缺漏**：用户可勾选/录入「我哪里薄弱」→ 写 `profile_trait_set(trait: "weakness_self")`；与系统算出的掌握度**分区展示、不混淆**（一个是"你说的"，一个是"统计的"）。
- **偏好与风格**：`preference` / `style` 的简单录入与展示。
- **诚实边界块**（§一 第 3 条的原文，**必须逐字**）：放在显眼位置，不是脚注。
- 页面需注明「**数据只在本机；不参与任何模型训练**」。
