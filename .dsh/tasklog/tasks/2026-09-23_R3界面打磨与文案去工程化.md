  6. **打包核验时的一次假警报（方法坑）**：用 `System.Drawing.Icon.ExtractAssociatedIcon` 抽主程序 exe 与包内悬浮球 exe 的内嵌图标，结果**悬浮球抽出来是一块纯绿方块、两者哈希不一致**，看着像"包内图标没打对"。改用 `PrivateExtractIcons`（按尺寸从图标资源组取）后**两者 `@256px`/`@32px` SHA256 逐位相同**，目视均为「晨光云朵」——**是取图方法错，不是产品缺陷**。已把这条写进 README 与交付说明，避免后人重复误判。
