- **关键决策**：
  - **不是"调一组蓝色"，而是把 DSH 的令牌层搬过来**：先把 `--dsw-static-*` / `--dsw-alias-*` 原样抄进 `styles.css`，
    再让春晓的 `--brand/--surface/--text/…` **指向**它们。结果：**组件 CSS 一行没改**、深色只覆盖 alias、
    108 条 UI 断言一条没红；以后 DSH 换主题只要重抄那两段。
  - **照 DSH 的口径取色**：DSH 的**主按钮是单色**（浅近黑 / 深白），蓝只用于链接与强调 ——
    所以 `--brand-solid`（按钮/实底）→ `brand-primary`，`--brand`（描边/圆点/渐变）→ 品牌蓝。
  - **用户气泡改用 DSH 的淡色底**（`--dsw-specific-bubble`）：DSH 的用户消息不是实心主色块。
  - **形象撞色要主动处理**：鲸鱼是蓝的，而 `.brand-mark` 原来是蓝底渐变、球面默认也是蓝 —— 两处都改近黑底盘。
  - **图标流水线的取景假设要迁就**：`make-icons.ps1` 按"母版视觉中心 (120,120)"取景，
    新母版因此缩放到 240×240、宽 180（否则图标里鲸鱼小到看不见）。
  - **主题有两份**（主进程 `skins.js` / 渲染进程 `panel.js`，渲染进程拿不到主进程代码）—— 已在两边注释点名同步。
