## §R5.1 紧急修复（同日，已发版出包 0.7.1）

- **触发（用户原话）**：「你都不给我问什么的输入框，只让我点问询我要问什么？」／「这个收起你是用哪个部位想出来的？收起以后 ui 怪异不说我甚至没法取消收起」／「我要的是有一个框可以拖入文本，再一个框可以写我要问什么，然后有一个按钮可以点击关联知识点，就这些」／「然后手动和自动抓取你也给我弄没了我真服了」。
- **根因（三条抱怨是同一个错误）**：用户机器上 `panelHeight: 64` + `panelCollapsed: true` —— 收起态窗口 64px，而收起态内容（输入框 38 + 按钮行 38 ≈ 100px）**装不下** → 按钮行被裁到窗口外 → 「展开」按钮**就在那一行里** → 出不来了；`panelCollapsed` 还持久化，**重启无效**。抓取模式那一版被换成了顶栏纯图标按钮，收起态下顶栏又被整块隐藏 → 等于消失。
- **处置**：
  1. **整块删除「收起」**：`panel:set-collapsed` IPC、`windows.applyCollapsedSize`、`PANEL_COLLAPSED_H`、`config.panelCollapsed`、渲染层 `.collapsed` 规则全部清掉；
  2. **配置自愈**（`config.load()`）：删 `panelCollapsed` 键 + `panelHeight` 低于下限拉回默认；
  3. **两个框**：`#source`「抓取的内容」+ `#question`「我要问什么」（回车=问询、Shift+回车换行，`isComposing`/229 时不发）；问询时内容作上下文、问题作问题，落库时把原文截断 2000 字并入记录；
  4. **恢复带文字的自动/手动抓取**（常驻正文，与设置抽屉同步）—— **带文字的功能入口不要再收成图标按钮**；
  5. **版面加固**：按钮行移出可压缩区（永不参与压缩）、结果区是唯一伸缩项（`min-height:44px`）、两个输入框按内容定高（第一版让它们一起压缩 → 实测出现源框底 342/问题框顶 346 的**重叠**）、输入框上限随视口（`min(150px, 24vh)`，resize 重算）、面板最小高度 420 → **460**；`⧉`(U+29C9) 在 Segoe UI 无字形渲染成白方块 → 换内联 SVG；结果区占位文案与常驻的停止按钮一并去掉（用户要求）。
  6. **新增 `scripts/smoke-ball-panel.ps1` + `.mjs`（面板版面守门）并进闸门第 9 步**。
- **本轮最该记住的**：0.7.0 的「闸门 8/8 · Rust 65/65 · UI 92/92 · 真机 18/18」**全都是真的**，却仍把用户卡死 —— 因为那 8 层里**没有任何一层渲染过面板本身**（面板是独立 Electron 窗口）。**覆盖面缺一块时，处置不是"以后小心点"，而是补上那一层并验证它能红。**
