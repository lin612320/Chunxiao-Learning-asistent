- **关键决策**：
  - 形象走 **「晨光云朵」**（云托朝阳，学生友好）；UI **保留春绿**只做精致化（不换品牌色 → 不必同步改悬浮球皮肤与语义色）
  - **一份母版两处消费**：界面用 `<img>` 引用同一份 SVG（不抄成 JSX），exe/favicon 由同一母版光栅化 → **从机制上根除"两套实现慢慢漂移"**
  - 光栅化**自建**而不是加依赖：Windows 没内置 SVG 光栅化器 + 项目零依赖约定 → 借已在用的 Edge 内核 + CDP；透明背景要**两道设置**（页面底色 + 截图 omitBackground），只做后者会得白底
  - 守住既有**对比度口径**：主按钮**不用**品牌渐变实底（渐变亮端配白字仅 ~3:1，会破坏已实测登记的 5.4:1）；厚度感改由内高光 + 多层阴影实现；hover 由"变亮"改"变深"
